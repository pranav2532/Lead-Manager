# Lead Manager

A simple CRM application for managing leads.

## Features

- User Authentication
- Dashboard Analytics
- Create Leads
- Update Leads
- Delete Leads
- Search & Filter
- Pagination
- Profile Management

## Tech Stack

Frontend:
- React
- CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

## Installation

### Backend

```bash
npm install
npm start
```

### Frontend

```bash
npm install
npm run dev
```

## Environment Variables

Create .env

```env
Mongo_URI=
Secret_Key=
```
